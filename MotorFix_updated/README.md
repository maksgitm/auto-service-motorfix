# MotorFix — обновлённая версия

## Структура
- `index.html` — главная
- `services.html` — каталог услуг
- `diagnostics.html` — новая страница с описанием процесса диагностики
- `tips.html`, `faq.html`, `contacts.html` — остальные страницы
- `js/` — скрипты сайта
- `css/style.css` — стили

## Важно при размещении
Загрузите содержимое папки проекта с сохранением структуры каталогов. Существующие локальные файлы Bootstrap (`js/bootstrap.bundle.min.js`) должны находиться в каталоге `js/`, как и в исходном проекте. Адрес `info@motorfix.example` оставлен таким, каким он был указан в исходниках; замените его на реальный адрес, если `.example` использовался как заглушка.


Дополнительно: в каталоге и популярных услугах кнопка «Подробнее об услуге» открывает развёрнутое описание с составом работ, результатом, временем и ориентировочной стоимостью. Показатели на главной странице анимированно считают значения при прокрутке к блоку. В подвал добавлен блок записи, заполняющий свободную правую часть.
